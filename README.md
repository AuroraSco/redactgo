# RedactGo 网站说明

[RedactGo](https://redactgo.com/) 是一个免费的在线 PDF 脱敏工具。它在浏览器中处理文件：选择需要遮盖的区域，检查实际生成的结果，再下载处理后的 PDF。无需注册，没有水印，未标记区域的文字尽量保持可搜索、可复制。

![RedactGo 标志](https://redactgo.com/brand/privacy-r.png)

## 适合做什么

- 在分享合同、表单、账单等 PDF 前，遮盖姓名、联系方式、编号、签名或图片中的局部信息。
- 在同一份文件的多个页面上绘制多个脱敏区域；支持撤销和整页脱敏。
- 处理后预览**实际输出的 PDF**，确认遮盖位置及其他内容，再决定是否下载。

“画一个黑框”并不一定等于安全脱敏。RedactGo 的处理目标是移除标记区域内的内容，而不是只叠加可移开的黑色图层。下载后仍应逐页检查结果，尤其是复杂或重要文件。

## 使用方法

1. 打开 [首页工具](https://redactgo.com/) 或两个专题页面：[在线 PDF 脱敏](https://redactgo.com/redact-pdf-online/) / [PDF 黑框脱敏](https://redactgo.com/blackout-pdf/)。三页使用同一工具。
2. 选择一份 PDF。单文件最大为 **10,000,000 字节**（约 10 MB）。
3. 在浏览模式查看页面；切换到画框模式后标记需要移除的区域。可按需撤销、切换页面或标记整页。
4. 执行脱敏，检查结果预览。如果还有遗漏，可以继续处理；确认无误后下载。
5. 处理完毕可清空当前文件，在本机打开下一份。

网站不设每日处理份数限制，也不要求账号。

## 隐私与处理边界

PDF 的预览和脱敏在用户浏览器内完成；文件字节不上传到 RedactGo 服务器。网站没有云端文件历史。清空工具会释放应用持有的文件引用并结束处理线程，但不会删除用户电脑上的原文件、下载文件，也不承诺清除操作系统的所有内存副本。

网站使用匿名完成次数统计，并接入 GA4 记录页面浏览及预定义的工具操作事件。统计事件不包含 PDF 文件名、正文、标记坐标或文件内容；统计服务失败不会阻止本地处理。网站显示的处理总数来自客户端完成上报，不是独立审计的文件数量。

## 已知限制

- 一次处理一份 PDF，文件不得超过上述大小限制。
- 为避免输出看似成功却未安全移除内容，加密 PDF，以及带有交互表单、注释、脚本/动作、标签结构、可选内容图层等不受支持的文件会被拒绝；处理失败时不会提供伪成功的下载。
- 基础元数据会被清理，但工具不能自动识别文档里所有敏感信息。使用者需要检查全文、图片、页眉页脚和最终下载文件。
- 复杂 PDF 的兼容性无法由有限测试完全证明；重要材料宜再用独立工具检查输出。

## 技术与开源

网站采用 Astro、React、TypeScript 和 PDF.js；MuPDF.js 在浏览器后台线程执行脱敏。静态页面和可选的匿名计数接口部署在 Cloudflare Workers。界面采用 Natural Organic 风格，标志使用深棕色隐私 R 图形。

RedactGo 应用代码以 **AGPL-3.0-or-later** 开源。网站的[源码与许可页面](https://redactgo.com/source/)提供当前部署版本的应用源码、许可证、第三方声明，以及对应 MuPDF 源码版本与校验信息。依赖各自保留原有许可证。

本说明描述当前已上线的功能与边界；网站功能更新时，应同步核对和更新本文。
